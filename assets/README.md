# Assets: The Systems Atlas

## `illustrations/` and `projects/*-art.svg`: drawn, not captured

Every drawing is generated by `tools/art/build.py` (Python standard library only, seeded, so the output
is reproducible). They share one palette, one line weight and one set of label styles.

| File | What it shows |
|---|---|
| `illustrations/hero-atlas.svg` | Plate 00: layered terrain, a skyline in the idiom of Bahawalpur's architecture, a branching tree that resolves into a network, a microscopy field. Also inlined in `index.html`. |
| `illustrations/bahawalpur-map.svg` | Stylised regional plan: river, canal and distributaries, walled city, palace garden, railway, desert and fort. Not to scale, not traced from any map. |
| `illustrations/contour-divider.svg` | Separator above the closing chapter |
| `illustrations/chapter-marks.svg` | Sprite of seven chapter glyphs (also inlined) |
| `projects/meritnama-art.svg` | Schematic: candidates by merit → preference flows → seat grid |
| `projects/nabz-art.svg` | Prescription sheet: English column, Urdu column, pulse trace |
| `projects/antibiome-art.svg` | Culture plate with disc-diffusion zones + resistance matrix |
| `projects/antibiotogram-art.svg` | Organism × agent coverage matrix, linked by drug class |
| `projects/nisbat-art.svg` | Day arc with prayer marks over a household, smog band |
| `projects/shaheen-art.svg` | Original falcon drawing + ranking ladder (not the clan's crest) |

The drawings are diagrams. None of them is presented as a product screenshot, and the values in them are
illustrative.
