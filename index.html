The nama design system

One skeleton,
one accent each.

Three of these projects had independently landed on the same easing curve, the same cool off-white ink and the same monospace-means-a-real-number rule. So I stopped treating that as coincidence and wrote it down.

Everything structural is shared — the void ground, IBM Plex against a serif display face, a 4px space scale, one curve for all motion. A family member differs by a single attribute, and the page you are reading re-tints itself through all seven as you move the carousel.

A little about the person

I usually start with
something that bothers me.

I build mostly because I run into things I don't understand, don't like, or think could work better. Python and JavaScript are where I'm comfortable; I learn whatever else a problem turns out to need.

I don't particularly care about using the fashionable stack. A complicated system becomes easier once you can see its pieces, and data is far more useful once someone can actually read it.

Some of these are used by thousands of people. Some are still experiments. Not every experiment needs to become a product — I built them because they mattered to me.
