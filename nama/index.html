n nama Previewing · MeritNama

Design system · v1 · 2026

One skeleton,
one accent each.

The shared design language of the nama family — MeritNama, medNAMA, Nabz, Antibiome and Antibiotogram. It was not designed up front. Three of these projects independently arrived at the same easing curve, the same cool off-white ink and the same rule about monospace numerals. This is that coincidence, written down and made deliberate.

See the accents nama.css ↗
01

The one idea

Everything structural is shared. What distinguishes a family member is its accent, set with a single attribute on <body>. Nothing else changes — not the type, not the spacing, not the radii, not the motion.

<!-- MeritNama -->
<body data-accent="meritnama">

<!-- medNAMA -->
<body data-accent="mednama">

<!-- Nabz: light clinical register -->
<body data-accent="nabz"
      data-register="clinical">
/* every component reads the same two vars */
.thing {
  border-color: var(--accent);
  background: var(--accent-wash);
  transition: border-color
    var(--t-base) var(--ease);
}

/* so re-tinting animates for free */

04

Type

A serif display face against IBM Plex Sans. The contrast between the two is the family's personality, so no third decorative face is ever added. Monospace is reserved: it means “this is a precise value”, which in Nabz is a dose-legibility safety property, not a style choice.

06

Motion

One curve: cubic-bezier(.2, .8, .2, 1). All three original repos had already converged on it, which makes it the family's truest signature — a fast start that settles rather than stops.

--ease · cubic-bezier(.2, .8, .2, 1)

Arrives early, decelerates long. Reads as weight.

linear · for comparison

Mechanical. The family never uses it for position.

--t-fast
160ms · hover, press

--t-base
260ms · state change

--t-slow
440ms · panels, reveals

--t-cine

07

Two registers

The void is the default: calm, dark, data-forward. The clinical register inverts the ground for anything a doctor uses at speed or a patient has to read on paper. Same structure, same tokens, opposite ground — Nabz ships light by default and never auto-switches to dark, because dark murders Nastaʿlīq legibility and trust.

08

The rules that actually bind

A token file is easy to follow. These are the parts that take discipline.

✓

Colour means something or isn't used. Accent for action and emphasis, teal for vetted, amber for unverified, red for danger. Everything else is ink.

✕

Red is never decorative. If red appears anywhere it isn't danger, it stops meaning danger — and then it stops working where it matters.

✓

Spend boldness in exactly one place per screen. One hero element carries the eye; everything around it stays quiet so it can.

✓

Encode state in more than one channel. Glyph plus border plus label. Colour reinforces; it never carries the message alone.

✕

No third typeface. The serif-against-Plex contrast is the personality. A display face added on top only dilutes it.

✓

Monospace means a precise value. Doses, IDs, ranks, counts. Keep it out of prose, and out of patient-facing Urdu entirely.

✓

Every animated primitive has a correct still state. Under prefers-reduced-motion the page must be finished, not frozen mid-entrance.

✕

Never the cream-paper cliché. Warm beige for “document” reads as generic. Warmth comes from the in-palette peach and rose instead.

09

Using it

One stylesheet, two attributes, three fonts. It is deliberately a plain CSS file with no build step — every family member can link it directly.
